# Provider access and data rights

Review date: October 24, 2026. This source distribution contains adapters and synthetic generators, **no vendor history, actual-price screenshot, API response dump, user key, or redistributed data service**. Open-source code does not license market data, index names, trademarks or downstream commercial display. Each person runs the viewer locally using their own lawful access.

| Source | Evidence and release treatment |
|---|---|
| Alpaca | [Official redistribution answer](https://alpaca.markets/support/redistribute-alpaca-api) says Alpaca API data cannot be redistributed. The release includes a read-only adapter; users provide their own approved access. No shared credentials, hosted relay or data archive. [Market-data documentation](https://docs.alpaca.markets/us/docs/about-market-data-api). |
| Cboe | [Use of Content](https://www.cboe.com/use-of-content/) requires advance approval and a signed agreement for Cboe website content, including data. A downloadable daily CSV does not establish reuse permission. Retrieval is disabled by default; `--cboe` is only for users with appropriate rights, not a grant or acceptance of terms. No permission request was submitted. |
| ECB | [Copyright conditions](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) permit use subject to accurate source attribution and explicit disclosure of modifications, with additional conditions for sold documents. The chart identifies ECB and states the derived basket calculation. No ECB logo is included. |
| US Treasury | The adapter uses the official [interest-rate data resource](https://home.treasury.gov/resource-center-data-chart-center/interest-rates). Source and percent-yield meaning remain visible. No bundled dataset or endorsement claim. |
| Binance | Uses documented [USDⓈ-M market-data APIs](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Kline-Candlestick-Data). Public endpoint access is not a general redistribution license; regional/service restrictions still apply. No alternate-domain bypass. |
| Hyperliquid / trade[XYZ] | Uses the documented [public info API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api). [Service terms](https://app.hyperliquid.xyz/terms) and upstream index/oracle rights are distinct from code licensing. No account, wallet, signing, order API or data redistribution grant is included. |
| Gate | Uses documented public market-data methods. [User agreement](https://www.gate.com/legal/user-agreement) covers APIs and TradFi assets and describes external-data delays/interruptions. No broad right to redistribute provider or underlying data was established. Optional candidates retain unknown-delay and proxy labels. |
| ICE / index construction | The indicative basket uses published six-currency weights/scaling described by [ICE](https://www.ice.com/forex/usdx). It is not an official ICE product or licensed ICE data feed. Mathematical implementation, trademark use, benchmark/product licensing and commercial derived-data rights are separate questions. No grant for an ICE-branded product is claimed. |

A standalone source release is the proposed scope. A public hosted dashboard, data export, actual-market screenshot, index product, or commercial redistribution would require a separate provider-rights assessment. The default synthetic demo avoids those data-distribution issues and can be used for screenshots if visibly labelled. This review records public terms and limits; it is not a legal clearance for every jurisdiction or use.

API failures such as 401/403/451 stop access. The application does not change regions, bypass restrictions, scrape authenticated pages, or use connector credentials. No new account, agreement, subscription or paid service is needed to run the synthetic demo.
